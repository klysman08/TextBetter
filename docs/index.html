Get Started in 3 Steps

Easy setup with zero complex configuration.

1

Install the Extension

Install TextBetter directly from the Chrome Web Store, or load it unpacked from GitHub for developer previews:

Install from Chrome Web Store
git clone https://github.com/klysman08/TextBetter.git
2

Get your Free Gemini API Key

Head to Google AI Studio, log in with your Google account, and generate a new API key in under 30 seconds.

3

Configure & Write Better

Open TextBetter settings, paste your key, and customize your trigger hotkey (default Ctrl+Shift+K). Highlight any text on any page to begin!
